> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在运营后台顶部标题栏下方新增二层导航栏（运营仪表盘 / 客户管理），支持 tab 切换视图，侧边栏按需显隐。

### Task 3: dashboard.html — 添加 tab 切换逻辑 + 侧边栏显隐

**Files:**
- Modify: `templates/dashboard.html` — 在 `<script>` 标签顶部添加 `switchTab()` 函数，修改 `showDashboard()` 和 `selectCustomer()` 以切换 tab 状态

- [ ] **Step 1: 在 script 顶部（`escapeHtml` 函数之后）添加切换逻辑**

在 `function escapeHtml(str) { ... }` 之后，`let selectedCustomerId = null;` 之前，插入：

```javascript
// ---- Tab 切换 ----
function switchTab(tab) {
  document.querySelectorAll('.nav-tab').forEach(el => {
    el.classList.toggle('active', el.dataset.tab === tab);
  });
  const layout = document.querySelector('.main-layout');
  if (tab === 'dashboard') {
    layout.classList.add('sidebar-hidden');
    showDashboard();
  } else if (tab === 'customers') {
    layout.classList.remove('sidebar-hidden');
    selectedCustomerId = null;
    loadCustomers();
    document.getElementById('detailPanel').innerHTML = `
      <div class="empty-state">
        <div class="icon">☀</div>
        <p>选择左侧客户查看详情</p>
      </div>
    `;
  }
}
```

- [ ] **Step 2: 修改 `showDashboard()` — 初始加载保持默认，每次调用设置 tab**

`showDashboard()` 函数开头已经是完整的仪表盘渲染逻辑，不需要改内容。但在 `selectCustomer()` 中，选中客户后需确保 tab 保持在 `customers` 状态（因为用户可能是从 sidebar 直接点客户）。

不需要修改 `showDashboard()` 本身。但需要确保 `selectCustomer()` 调用时将 tab 切换到 `customers`。

在 `selectCustomer(id)` 函数的第一行 `selectedCustomerId = id;` 之后，`loadCustomers()` 之前，插入：

```javascript
  document.querySelectorAll('.nav-tab').forEach(el => {
    el.classList.toggle('active', el.dataset.tab === 'customers');
  });
  document.querySelector('.main-layout').classList.remove('sidebar-hidden');
```

- [ ] **Step 3: 修改初始化逻辑**

页面底部 `showDashboard();` 保持不变 — 默认加载仪表盘。但需要追加侧边栏隐藏：

将最后一行 `showDashboard();` 替换为：

```javascript
showDashboard();
document.querySelector('.main-layout').classList.add('sidebar-hidden');
```

2. 在 `dashboard.html` 的 `switchTab()` 函数中添加 `else if (tab === 'xxx') { ... }` 分支
