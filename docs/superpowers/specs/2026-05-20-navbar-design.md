# 运营后台二层导航栏设计

## 背景
当前运营后台仅有一个单页面，点击左侧客户后仪表盘视图被替换为客户详情，
用户无法直观回到仪表盘。需要在顶部标题栏下方新增第二层导航栏，
支持在「运营仪表盘」「客户管理」及后续模块之间切换。

## 改动范围
- `templates/base.html` — 在 navbar 下方新增 `.nav-tabs` 结构
- `templates/dashboard.html` — 添加视图切换逻辑，两视图（仪表盘／客户管理）
- `static/style.css` — 新增 nav-tabs 样式 + 侧边栏显隐规则

## 导航结构

```
[Logo] 新华智科技   |   太阳能即付即用系统   |   退出        ← 现有 titlebar，不动
─────────────────────────────────────────────────────────────
  运营仪表盘  |  客户管理  |  [未来模块...]                  ← 新增 .nav-tabs
─────────────────────────────────────────────────────────────
```

## 交互行为
- 页面默认激活「运营仪表盘」tab，显示 KPI 首页
- 点击「客户管理」tab，显示客户列表（侧边栏 + 空状态提示）
- 点击左侧客户 → 自动切换到客户详情，tab 保持「客户管理」
- 点击「运营仪表盘」tab → 回到 KPI 首页
- 激活 tab：绿色文字 + 底部边框下划线

## 侧边栏行为
- 仪表盘视图：侧边栏隐藏（不需要选客户）
- 客户管理视图：侧边栏显示
- 未来模块按需决定侧边栏显隐

## 可扩展性
新增模块只需：在 .nav-tabs HTML 加一个 `<a>`，在 JS 的 tab 声明对象加一个 key，
无需改动 CSS 或其他逻辑。
